# 00 — 인테이크: 자율 실행·피드백 루프

작성일 2026-08-29 · 기준 커밋 `974c3d5` · 대상 브랜치 `main`

## 요구 유형과 목적

기존 ChatGPT To Codex의 로컬 편집·명령·E2E 도구를 묶어, 사용자가 매번 개발 결과를 직접
실행하고 다시 설명하는 반복을 제거한다.

두 전달물을 함께 계획한다.

1. **방법 A — 현재 ChatGPT 흐름 안의 실행·검증·자기개선 루프:** ChatGPT가 한 요청을
   끝내기 전에 구현, 로컬 실행, 증거 수집, 수정, 재검증을 반복한다. 사람이 남긴
   “무엇이 왜 틀렸는지” 피드백은 다음 요청에서도 재사용할 수 있게 저장하고, 반복 실패가
   쌓이면 같은 ChatGPT 흐름에서 작은 Skill 수정안을 만든다. 수정안은 자동 적용하지 않고
   사람이 검토하는 Git PR로만 전달한다.
2. **방법 B — 대화 종료 후 백그라운드 연속 실행:** 로컬 런타임이 검증 결과를 감지해 별도
   OpenAI API 에이전트 세션을 실행하고 다음 개발 단계를 진행한다.

## 핵심 경계

- `CONFIRMED`: `src/state/work-queue.ts`는 “MCP is a pull protocol: the server only ever
  answers”라고 명시한다. MCP 서버는 종료된 ChatGPT 웹 대화에 새 메시지를 먼저 보낼 수 없다.
- `CONFIRMED`: 기존 `goal_loop`는 다음 행동을 반환하지만, 다음 호출은 ChatGPT가 해야 한다.
- `CONFIRMED`: OpenAI의 ChatGPT MCP 앱 문서는 사용자가 채팅에서 앱을 선택하거나 언급해
  호출하는 흐름을 설명하며, MCP 서버가 채팅을 먼저 시작하는 계약을 제공하지 않는다.
- `INFERRED`: 방법 B를 사람 개입 없이 구현하려면 ChatGPT 웹 대화가 아니라 로컬 프로세스가
  소유하는 모델 API 세션이 실행 주체가 되어야 한다.

따라서 방법 B의 제품 문구는 **“ChatGPT 웹 대화 자동 재개”가 아니라 “OpenAI API 기반
백그라운드 에이전트 실행”**으로 고정한다. 공식적인 ChatGPT 대화 push API가 확인되기 전에는
브라우저 자동 입력, 비공개 ChatGPT API, 세션 쿠키 재사용을 구현하지 않는다.

## 대상 사용자

로컬 저장소를 ChatGPT To Codex로 개발하는 단일 소유자. 팀용 공유 실행기, SaaS 호스팅,
운영 배포 자동화는 범위 밖이다.

## 핵심 사용자 흐름

### 방법 A

1. 사용자가 구현 목표와 최대 반복 수를 한 번 입력한다.
2. ChatGPT가 `goal_loop`와 로컬 도구로 코드를 수정한다.
3. 검증 실행기가 타입 검사, 테스트, 빌드, 로컬 시나리오를 실행해 구조화된 결과를 반환한다.
4. 실패하면 `goal_loop`가 실패 증거를 다음 수정 단계 입력으로 사용한다.
5. 전부 통과하거나 중단 조건에 도달했을 때만 최종 보고한다.
6. 사용자가 결과를 교정하면 “무엇이 틀렸는지, 왜 틀렸는지, 어느 Skill과 관련 있는지”를
   명시적으로 확인한 뒤 feedback record로 저장한다. 원문 대화 전체는 저장하지 않는다.
7. 동일 Skill에 재사용 가능한 피드백이 3건 이상 쌓이면,
   현재 ChatGPT가 improver 역할로 피드백을 묶어 한 Skill 파일만 건드리는 작은 patch를 제안한다.
8. patch는 proposal 상태로 보관한다. 사용자가 승인한 경우에만 기존 guarded Git/GitHub 흐름으로
   branch/PR을 만들며, merge는 사람이 수행한다.

### 방법 B

1. 사용자가 프로젝트별 백그라운드 작업과 예산을 명시적으로 활성화한다.
2. 로컬 작업 큐의 이벤트가 지속 작업 레코드를 만든다.
3. 로컬 API 에이전트가 모델 응답과 허용된 로컬 작업을 반복 실행한다.
4. 재시작 후에도 미완료 작업을 복구한다.
5. 성공, 정책 차단, 비용 한도, 반복 한도 중 하나로 종료하고 대시보드에 증거를 남긴다.

## OUT_OF_SCOPE

- ChatGPT 웹 UI에 자동으로 텍스트를 입력하거나 전송하는 데스크톱 자동화.
- ChatGPT 소비자 계정의 쿠키·세션·비공개 API 사용.
- 사용자 승인 없는 `git push`, 배포, 이메일·메시지 전송, 운영 데이터 변경.
- 피드백만으로 Skill 파일을 자동 수정하거나 PR을 자동 merge하는 동작.
- 대화 원문 전체, 사용자 메시지 전체, 코드·로그 원문을 학습 자료로 장기 저장하는 동작.
- 임의 셸 명령 허용, 기존 프로젝트 경로 confinement 완화, secret redaction 완화.
- 여러 사용자의 비용·권한·작업을 분리하는 멀티테넌트 서비스.
- 방법 B가 방법 A보다 먼저 출시되는 순서.
