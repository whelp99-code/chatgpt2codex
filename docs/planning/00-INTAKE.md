# 00 — 인테이크: 다중 세션 작업 현황판

작성일 2026-08-16 · 대상 저장소 `/Volumes/DevSpace/Playground/chatgpt2codex-repo`

## 요구 유형

기능 추가 (기존 `/admin` 대시보드 확장). 신규 서비스나 외부 연동 없음.

## 목적

ChatGPT 대화창을 여러 개 띄워 서로 다른 프로젝트를 동시에 작업할 때, 지금 무엇이 어디까지
진행됐는지 한 화면에서 파악한다. 현재 대시보드는 슬롯 목록을 보여주지만 **어느 창이 일하는
중이고 어느 창이 손을 놓았는지 구분되지 않으며**, 세션 라벨이 `W01` 같은 내부 기호라 어떤
프로젝트인지 표에서 눈으로 좇아야 한다.

## 대상 사용자

저장소 소유자 1인 (오너 토큰 보유자). 다중 사용자·팀 공유는 범위 밖.

## 핵심 흐름

1. 소유자가 ChatGPT 대화창 3개를 열고 각각 다른 프로젝트를 `project_select` 한다.
2. `/admin`을 연다.
3. 각 세션이 `프로젝트폴더명 (W01)` 형태로, `진행중 / 대기` 상태와 함께 보인다.
4. 대화창을 닫으면 그 세션이 `완료`로 넘어가 이력 영역에 며칠간 남는다.

## 확정된 요구사항 (사용자 결정 완료)

| # | 내용 | 결정 근거 |
|---|---|---|
| 1 | 서로 다른 프로젝트 동시 처리 | 이미 동작 — 검증과 회귀 테스트만 |
| 2 | 대기/진행중/완료 자동 판정 | 사용자 선택: 활동 기반 자동 (명시적 작업 등록 방식 기각) |
| 3 | 세션 이름 `폴더명 (W01)` 병기 | 사용자 선택: 같은 프로젝트 다중 창 구분 필요 |
| 4 | 완료 이력 하루~며칠 디스크 보관 | 사용자 선택: 메모리 전용·보관 안 함 모두 기각 |
| 5 | 피어(다른 머신) 조작 없음 | 사용자 선택: 자기 인스턴스만 |

## OUT_OF_SCOPE (명시적 제외)

- **피어 인스턴스 조작.** 피어 상태를 *읽어* 표시하는 기존 동작은 유지하되, 피어의 세션을
  끊거나 상태를 바꾸는 기능은 만들지 않는다.
- **세션 강제 종료 / 리스 회수 버튼.** 앞서 논의된 "컨트롤러화" 1번 항목. 이번 범위는 읽기
  전용 현황판이며 `/admin`은 GET만 유지한다.
- **명시적 작업(task) 등록 도구.** 대화창이 "무슨 일을 하는지" 직접 적는 MCP 도구는 만들지
  않는다. 상태는 전부 활동에서 파생한다.
- **워크스페이스 전환 UI.** 맥 앱의 `selectedProjectFolder`가 `workspaces.txt`를 덮어쓰는
  기존 충돌은 이번에 건드리지 않는다.
- **인증 방식 변경.** 오너 토큰과 `c2c_admin` 쿠키 구조를 그대로 쓴다.
